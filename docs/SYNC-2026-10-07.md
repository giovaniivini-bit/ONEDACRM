# Atualização de fotos e Prog Feira

O índice de fotos combina arquivos existentes com a página pública da pasta e sua listagem incorporada (`embeddedfolderview`). A segunda listagem encontrou as imagens 01.16.42.0578 e 01.16.42.0579, ausentes nas janelas da primeira. O código completo do produto continua sendo respeitado.

O navegador consulta as fontes externas e o índice de fotos a cada minuto enquanto está visível, e ao retornar à aba. A VPS reutiliza o índice e as planilhas por até cinco minutos. Não há varredura automática quando nenhum navegador faz consultas. Dados iguais não provocam uma nova renderização das planilhas.

O botão Sincronizar Sheets atualiza a planilha principal, aguarda a indexação das fotos e força a consulta das planilhas externas, incluindo Prog Feira. Uma fonte que falhar não impede a aplicação das demais; o usuário recebe aviso de atualização parcial. Sincronizar Fotos força a indexação. Cada indexação invalida o cache das miniaturas conhecidas, para reconhecer substituições que mantêm o ID do Drive.

A leitura continua pública e depende do formato disponibilizado pelo Google; não equivale a uma API autenticada com paginação garantida. Falhas de rede preservam os arquivos já conhecidos. As requisições de listagem têm prazo e limite de tamanho.

Após publicar esta versão, recarregar uma vez as abas antigas para ativar a consulta periódica.
